# lbyxiafei/homebrew-tap

Homebrew casks for lbyxiafei's macOS apps.

```bash
brew install --cask lbyxiafei/tap/island
```

| cask | what it is |
|---|---|
| `island` | Pops up at the top of the screen when a local AI agent (Claude Code, Codex, pi) finishes a task. Signed and notarized. |

Release assets (the dmgs) are attached to this repo's GitHub Releases; the casks are generated by each app's publish script, so don't edit them by hand.
